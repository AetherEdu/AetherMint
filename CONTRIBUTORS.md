# Contributors

AetherMint is built by its community. Thank you to everyone who has contributed
code, documentation, design, testing, and feedback.

## Where to see the contributor list

The authoritative, always-up-to-date list of contributors is generated by GitHub:

- **Contributors graph**: <https://github.com/AetherEdu/AetherMint/graphs/contributors>
- **Commit history**: `git shortlog -sne --all`

We intentionally do not maintain a hand-edited name list here, because it drifts
out of date as soon as it is written. The GitHub graph above is the single source
of truth.

## How to be credited

Any merged contribution — a bug fix, a feature, documentation, a test, a
translation, or a design asset — is automatically credited through your Git
commit author information.

To make sure your credit is accurate and consistent across the project:

1. Set your Git identity before committing:
   ```bash
   git config user.name "Your Name"
   git config user.email "you@example.com"
   ```
2. If you contribute under more than one name or email address and want them
   merged into a single identity, add an entry to [`.mailmap`](.mailmap) in your
   pull request (see `git help shortlog` for the format).

## Recognition

We are grateful for every contribution, large or small. Maintainers may also
highlight significant contributions in release notes and in the project's
[GitHub Discussions](https://github.com/AetherEdu/AetherMint/discussions).
