## 🌓 Dark Mode

AetherMint supports dark mode via the `dark` class on the `<html>` element, following Tailwind's
dark mode strategy. Components use `dark:` variants to adjust colors:

```css
/* Example: card background adapts to dark mode */
.bg-white dark:bg-gray-800
.text-gray-900 dark:text-gray-100
.border-gray-200 dark:border-gray-700
```

Toggle dark mode in Storybook using the **☀️/🌙** button in the toolbar.
